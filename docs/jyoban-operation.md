# 上下番だけの運用（2026-11）

要件定義（MAMOR-AI 統合構成設計・要件定義 第4.1節）の第1段階。上下番と本日の現場一覧だけで運用を始め、ほかの機能は画面から外す。

## 画面に出るもの

| 役割 | 出る画面 |
| --- | --- |
| 現場PC（/s） | 本日の現場一覧（自現場）、勤務員登録・PIN |
| 本社PC（/co） | 本日の現場一覧（自社の全現場） |
| 支店・権限者（/co） | 本日の現場一覧（担当現場）、上番報告設定 |
| 管理者（/co） | 本日の現場一覧、上番報告設定 |
| 教育センター（/co） | なし（「いまは上下番の運用だけ」と表示） |
| 勤務員アプリ（/app・QR） | 上番報告だけ（シフト希望・有給・講習会・お知らせのタブは出さない） |
| 運営（/tradmin） | 従来どおり |

外したもの（日報・シフト・AIシフト・配置・有給・教育・通知など）は、データと仕組みを残している。
戻すときは Vercel の環境変数 `VITE_OPERATION_MODE=full` を追加して公開し直す（未設定＝上下番だけ）。

## できること（要件 R2・R4・R5・R6）

- **約定人数（R2）**：上番報告設定の勤務枠で、曜日ごと（日〜土）に約定人数を入れる。一覧で「上番 2／約定 3」と出し、上番の締切＋猶予を過ぎて足りなければ「未連絡」（赤）。0名の曜日は稼働なし。未設定なら配置者の人数、配置者もいなければ1名。
- **勤務員は取り消せない（R4）**：勤務員アプリの「取り消す」をなくし、台帳側でも呼べなくした。誤りは現場PC・本社PC・支店・管理者が一覧の「訂正」から直す。
  - 取り消す：理由が必須。記録は消えず、取消の理由・誰が直したか（メール、または「現場PC（現場名）」）が残る。
  - 後から登録：スマホを忘れた等。種類・スタッフNo・時刻・理由を入れる。「訂正あり」の印が付く。
  - 訂正の履歴は `jyoban_report_corrections` に残る。
- **勤務表外（R5）**：勤務枠の配置者に入っていない人も上下番できる。配置者を登録している勤務枠では「勤務表外」の印が付く。
- **シフト記入なし（R6）**：配置者を登録しなくても、約定人数と上番した人数で判定する。この場合「誰が未連絡か」は分からないので、本人への通知・SMS・電話は送れない（不足は一覧で赤くなる）。
- 位置確認（0412）の結果は、一覧の上番・下番の横に「範囲外」「位置なし」として出る。
